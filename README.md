# Team5 테트리스 게임

자바스크립트와 HTML5 캔버스를 활용하여 개발된 테트리스 게임입니다. 이 게임은 클래식 테트리스의 모든 기능을 구현하였으며, 여러 가지 확장 기능을 추가하였습니다.

![Team5 테트리스 게임 스크린샷](https://via.placeholder.com/800x400?text=Team5+Tetris+Game)

## 주요 기능

- **7가지 다양한 블록 모양**: 기본 테트리스 블록 7종류가 모두 구현되어 있습니다.
- **블록 회전**: Z와 C 키를 통해 블록을 왼쪽, 오른쪽으로 회전할 수 있습니다.
- **블록 저장 기능**: Shift 키를 사용해 현재 블록을 저장하고 필요할 때 교체할 수 있습니다.
- **다음 블록 미리보기**: 다음에 등장할 2개의 블록을 미리 확인할 수 있습니다.
- **점수 시스템**: 블록을 한 줄 완성할 때마다 점수가 증가하며, 일정 점수에 도달하면 게임 속도가 증가합니다.
- **게임 오버 시스템**: 블록이 맨 위에 닿으면 게임이 종료됩니다.
- **배경 음악과 효과음**: 게임에 몰입감을 더해주는 배경 음악과 다양한 효과음이 구현되어 있습니다.

## 조작 방법

| 키 | 기능 |
| --- | --- |
| ← → | 블록 좌우 이동 |
| ↑ | 블록 천천히 떨어뜨리기 |
| ↓ | 블록 빠르게 떨어뜨리기 |
| Z | 블록 왼쪽으로 회전 |
| C | 블록 오른쪽으로 회전 |
| Shift | 블록 저장 |
| 스페이스바 | 블록 즉시 떨어뜨리기 |
| B | BGM 켜기/끄기 |

## 게임 구현 상세

### 게임 로직

- **2차원 배열 활용**: 테트리스 게임판을 2차원 배열로 구현하여 블록의 위치와 충돌 검사를 효율적으로 관리합니다.
- **블록 랜덤 생성**: 7가지 블록이 중복 없이 랜덤하게 생성되어 게임의 다양성을 높였습니다.
- **충돌 감지**: 블록이 바닥에 닿거나 다른 블록과 겹칠 때 적절한 동작을 수행합니다.
- **줄 제거 시스템**: 한 줄이 모두 채워졌을 때 해당 줄을 제거하고 위의 블록들을 아래로 이동시킵니다.

### 그래픽

- **HTML5 캔버스**: 게임 화면 렌더링을 위해 HTML5 캔버스를 사용하였습니다.
- **색상 다양화**: 각 블록 타입별로 다른 색상을 적용하여 시각적 구분을 용이하게 하였습니다.

### 사운드

- **배경 음악**: 게임 진행 중 배경 음악이 재생됩니다.
- **효과음**: 블록 회전, 이동, 줄 제거 등의 액션에 효과음을 추가하여 게임 경험을 향상시켰습니다.
