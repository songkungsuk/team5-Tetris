#### 1. 테트리스 배경
   캔버스를 사용하여 디스코드 자료실에있는 배경이 검은색과 유사하게 꾸며주시면 됩니다
   블록을 저장하는곳, 다음 블록이 나와야하는곳. 키설명같은걸 고려해서 꾸며주시면 되겠습니다~
   
#### 2. 블록
   https://ljh3326.tistory.com/14 를 참조하여 
   다음과같이 7개의 모양의 블록을 캔버스에 그릴수있게함
